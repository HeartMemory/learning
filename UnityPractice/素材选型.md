# 🎯 素材选型：立项时怎么挑素材

> **分工**：本文只写「**怎么挑**」。
> 「**clone 后怎么把素材装回来**」→ [素材还原.md](素材还原.md)｜「**哪些能进仓库**」→ [.gitignore](.gitignore) 第 ⑦ 区。
>
> **适用**：某个 demo 要新建 / 要加一类动作（走跑、攻击、UI 图标、音效…）时，先按本文走一遍再动手。

---

## 一、先问自己 5 个问题（需求不清就别开搜）

| # | 问题 | 为什么必须先答 |
|---|---|---|
| 1 | **要几个方向**？（只要前向 1 个 / 四向 / 八向） | 决定要不要找 strafe；1 个方向的包满地都是，八向的很少 |
| 2 | **要几档速度**？（只走 / 走+跑 / 走+跑+冲刺） | 2D Blend Tree 的"同方向多档"靠它 |
| 3 | **要原地版还是带位移版**？ | **Blend Tree 必须用原地版**；带位移版只在"位移由动画驱动"时用 |
| 4 | **风格取向**？（写实 / 低模卡通） | **一个 demo 内必须统一**，混风格最伤观感 |
| 5 | **能否接受付费**？上限多少 | 免费包经常"方向不全"或"只给 60~70%" |

## 二、候选源对照（2026-10-27 实测/查证，会过期）

| 源 | 许可 | 方向性 locomotion | 代价 / 已知限制 |
|---|---|---|---|
| **Unity Asset Store · Human Basic Motions FREE**（Kevin Iglesias） | Asset Store EULA（可商用；**原文件不可再分发**） | ✅ **走 8 向 + 跑 8 向**（各 0.80 / 0.60 s，已勾 Loop，**都有原地版**）+ 冲刺 5 向 | 需**自己的 Unity 账号** `Add to My Assets`（免费）；100+ 个 fbx，包体 ~56 MB |
| **Quaternius Universal Animation Library**（UAL1 / UAL2） | **CC0**（可自由再分发） | ⚠️ **免费档只给 60~70%**；实测手上的 UAL1（43 剪辑）**全是前向**，无 strafe | 完整版含更多动作；官网**无逐条清单**，只能下载后验 |
| **KayKit Character Animations**（1.1） | **CC0** | ⚠️ **跑左右 + 走后退有，走左右没有**（档位不对称 ⇒ 混合会跳档） | 自有骨骼，非 KayKit 角色需 retarget |
| **Mixamo**（Adobe） | 免版税可商用 | ✅ 有 left / right strafe | ⚠️ 官方 FAQ：**`country code` 为中国的账号不可用**；2000+ 库里要靠搜，命名乱 |
| **GitHub 上的零散 FBX 仓库** | ⚠️ **多数没有 LICENSE = 保留所有权利** | 不确定 | **"能在 GitHub 看到" ≠ "能用"**，先看 LICENSE |

> 📌 **判据**：**先看许可，再看方向**。许可不清的包，功能再好也不能进项目。

## 三、验证：别信商店文案，去读文件的嘴

### 手法 A · 还没导入（读 FBX 二进制里的剪辑名，30 秒）

```powershell
$p = 'D:\路径\包.fbx'
$txt = [System.Text.Encoding]::ASCII.GetString([System.IO.File]::ReadAllBytes($p))
[regex]::Matches($txt, '[A-Za-z][A-Za-z0-9_]{3,}') | ForEach-Object { $_.Value } |
  Sort-Object -Unique |
  Where-Object { $_ -match '(?i)(walk|run|strafe|left|right|back|jog|sprint|idle)' }
```

**压缩包不必解压**也能读（直接读 zip 里那一项）：

```powershell
$zip = [System.IO.Compression.ZipFile]::OpenRead('D:\路径\包.zip')
$e = $zip.GetEntry('包/Animations/Movement.fbx')
$ms = New-Object System.IO.MemoryStream; $e.Open().CopyTo($ms)
$txt = [System.Text.Encoding]::ASCII.GetString($ms.ToArray())
($txt | Select-String -Pattern 'Walk|Run|Left|Right|Back' -AllMatches).Matches.Value | Sort-Object -Unique
$zip.Dispose()
```

### 手法 B · 已导入工程（读 Rig / Avatar / Loop 的真状态）

Unity 里选中 fbx → 检查器 `Rig` / `Animation` 页；或用 Unity MCP 的 `execute_code` 直接读：

```csharp
var mi = UnityEditor.AssetImporter.GetAtPath(path) as UnityEditor.ModelImporter;
// mi.animationType == ModelImporterAnimationType.Human   ⇒ Humanoid
// mi.sourceAvatar.isHuman / .isValid == true             ⇒ 能重定向到别的角色
var st = UnityEditor.AnimationUtility.GetAnimationClipSettings(clip);
// st.loopTime == true                                    ⇒ 已勾循环
```

## 四、"能不能用"的判据清单

| # | 判据 | 通过标准 |
|---|---|---|
| ① | **许可** | CC0 / 商店 EULA（可商用）**且已知能否再分发** |
| ② | **方向覆盖** | 与需求 §一 一致；**注意档位是否对称**（走有左右、跑没有 ⇒ 混合跳档） |
| ③ | **原地版** | **有**（文件名常带 `[RM]` / `_RM` 的是**带位移**版，没有后缀的才是原地） |
| ④ | **循环** | 位移类剪辑 `Loop Time` 已勾 |
| ⑤ | **骨骼** | `Rig = Humanoid` 且 `Avatar.isValid = true`（否则要手工映射骨骼） |
| ⑥ | **材质** | URP 工程里不粉红（粉红 = Built-in 材质，需升级或换包） |
| ⑦ | **比例** | 拖进场景不出现 100× 缩放 / 朝向相反 |
| ⑧ | **体积** | 能否接受（>100 MB 的包要单独考虑，且**原文件一律不进 git**） |

## 五、入库口径（写完代码才谈这个）

| 素材许可 | 进 public 仓库？ |
|---|---|
| **CC0** | ✅ 可以（但仍要防仓库膨胀） |
| **Asset Store EULA** | ❌ **只进 `.meta` 与代码，本体排除**（EULA 禁止再分发源文件） |

具体规则与还原步骤见 [素材还原.md](素材还原.md)；忽略规则见 [.gitignore](.gitignore) 第 ⑦ 区。

## 六、常见坑（都真踩过）

| 坑 | 说明 |
|---|---|
| **"8 方向"不等于"带原地版"** | 商店页只写方向数，**在不在原地**必须读文件确认 |
| **免费版 ≠ 完整版** | Quaternius 免费档只给 60~70%；Iglesias 免费版给"方向性走跑"，付费版给"蹲走/游泳/社交" |
| **`[RM]` / `_RM` 后缀** | = Root Motion 版（位移烘焙进剪辑）；**Blend Tree 用了它会把人拽着走** |
| **URP 粉红** | 装了 Built-in 版资源；优先挑标注支持 URP 的包 |
| **骨架不统一** | 每家骨骼命名不同，跨包混用必须走 Humanoid 重定向 |
| **一个 demo 混两种风格** | 观感最伤；宁可用同一家的低模，也不要写实+卡通混着来 |
