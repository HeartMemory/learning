# 🔧 素材还原说明（clone 后必读）

> **一句话**：本仓库**只提交 Unity 工程本身**（脚本 / 场景 / 预制体 / 材质 / 动画控制器 / 全部 `.meta`），
> **Asset Store 素材的原始文件不进仓库**。换设备 clone 下来后，按本文装回素材包即可，**引用会自动恢复，不用手工重连**。
> 适用工程：`UnityPractice/AnimLab/`（当前唯一一个）

---

## 一、为什么这么做

| 原因 | 说明 |
|---|---|
| **许可限制** | Unity Asset Store EULA 允许你把素材**用**在作品里（含商业发行），但**禁止再分发原始资源文件**（§2.2.1.1(d) / §5.1 / Terms §3.5）。公开仓库里的 `.fbx` / `.png` 就是"谁都能拿走直接用"的源文件 |
| **仓库体积** | `Starter Assets` 的原文件约 **90 MB**（其中 12 个 `.tif` 就 70 MB），远超正文内容（代码与配置只有 ~3 MB） |
| **CC0 素材例外** | 若素材是 **CC0**（如 Quaternius Universal Animation Library），允许自由再分发 ⇒ **可以进仓库**，不受本文限制 |

---

## 二、仓库里有什么 / 没有什么

| 内容 | 在仓库里？ | 说明 |
|---|---|---|
| `*.cs`（脚本） | ✅ 有 | 场景上的组件引用靠它，缺了会 `Missing Script` |
| `*.prefab` / `*.controller` / `*.mat` / `*.asset` / `*.inputactions` / `*.shader` | ✅ 有 | 结构与配置 |
| **`*.meta`（全部）** | ✅ **有** | ⭐ **GUID 的唯一来源** —— 这是"装回素材包后引用自动恢复"的关键 |
| `*.fbx` / `*.png` / `*.tif` / `*.exr` / `*.wav`（在 `Assets/Starter Assets/` 下） | ❌ **没有** | 由本文第二节的素材包提供 |
| `Library/` `Temp/` `Obj/` 等缓存 | ❌ 没有 | Unity 自动重建 |

> ⚠️ **绝对不要**为了"省事"把 `*.meta` 也忽略掉：那样 GUID 会变，场景 / 预制体 / 材质引用**全部断裂**，只能手工重连 24 个 Prefab。

## 三、还原步骤

### 0. 前置（任何人照着做都一样）

| 项 | 要求 |
|---|---|
| **Unity** | **6.3 LTS（6000.3.x）+ URP**；作者在 `6000.3.23f1` 上验证过，相邻小版本一般也兼容 |
| **Unity 账号** | **你自己的账号**即可（**免费 Personal 许可就够**，不需要 Plus / Pro）。Asset Store 的免费资源是**按账号授权**的：**每个人都要用自己的账号点一次 `Add to My Assets`**，资源才会出现在**你自己**的 `My Assets` 列表里 ⇒ **不能直接拿别人下载的文件**（也不该拿：许可不允许再分发），但**自己 Add 一次是免费的** |
| **网络** | 需要在 `assetstore.unity.com` 与 Unity 客户端内操作（国内网络访问商店可能需要代理） |
| **操作前** | **先在 Unity 里关闭该工程**，否则文件被占用会导致导入失败 |
| **界面语言** | 本文按**中文界面**写，括号内给英文名（如 `Window → Package Manager`），界面是英文的照括号里的点 |

### 1. `Starter Assets`（第三人称控制器 —— 必需）

| 步 | 操作 |
|---|---|
| 1 | 浏览器打开 **`https://assetstore.unity.com/packages/essentials/starter-assets-thirdperson-updates-in-new-charactercontroller-pa-196526`** |
| 2 | ⭐ **必须选 `Starter Assets - ThirdPerson \| URP` 这个版本**（Built-in 版**不兼容 URP**，装错 = 全粉红） |
| 3 | **登录你自己的 Unity 账号**（免费 Personal 即可，买不买会员都跟这一步无关）→ 点 **`Add to My Assets`**（加入你自己的资产列表，免费资源不扣费） |
| 4 | 回 Unity → **`窗口 → 包管理器`**（`Window → Package Manager`）→ 左上角下拉切 **`我的资产`**（`My Assets`）→ 搜 `Starter Assets` → **`下载`**（`Download`）→ **`导入`**（`Import`） |
| 5 | ✅ **导入路径必须是 `Assets/Starter Assets/`**（包的默认路径，**不要改名、不要挪目录**） |

### 2. `Human Basic Motions FREE`（走跑 8 方向动画 —— 做 2D Blend Tree 时用）

| 步 | 操作 |
|---|---|
| 1 | 打开 **`https://assetstore.unity.com/packages/3d/animations/basic-motions-pack-154271`** → 用**你自己的账号**点 `Add to My Assets` |
| 2 | 同上：`窗口 → 包管理器`（`Window → Package Manager`）→ `我的资产`（`My Assets`）→ 搜 `Basic Motions` → `下载` → `导入` |
| 3 | ✅ **落到 `Assets/Kevin Iglesias/Human Animations/`**（包的默认路径，别改名） |
| 4 | 免费版就够：**Walk 8 方向 + Run 8 方向**（各 0.80 s / 0.60 s，已勾 Loop，**都带原地版**）+ Sprint 5 方向 + Jump + Turn + Idle；付费完整版**不需要** |

> ⭐ **命名判据（用之前必须先看懂）**：同一动作有两个版本，靠**文件名后缀**区分 ——
> - **不带 `[RM]`** = **原地版**（in-place）⇒ **Blend Tree 必须用这个**
> - **带 `[RM]`** = 带 Root Motion（位移烘焙进剪辑）⇒ 只在"位移由动画驱动"时才用
> - 例：`HumanM@Walk01_Left.fbx`（原地） ↔ `HumanM@Run01_Left [RM].fbx`（有位移）
> - 另外它的动画剪辑**挂在自己的 `HumanM_ModelAvatar` 上**（`isHuman = true`）⇒ 播到别的角色上会**自动重定向**，不用手工换 Avatar

### 3. `Quaternius Universal Animation Library`（CC0，**已在仓库里，无需还原**）

`Assets/AnimLab/Animations/UAL1_Standard.fbx` 是 CC0 素材 ⇒ 直接随仓库来，**不用下载**。

## 四、装完怎么验（三条判据，缺一不可）

| # | 判据 | 怎么看 |
|---|---|---|
| ① | **无 `Missing Script`** | 打开 `Assets/Scenes/Lab.unity`，选中 `PlayerArmature`，检查器里 **8 个组件都有内容**（`Animator` / `CharacterController` / `ThirdPersonController` / `BasicRigidBodyPush` / `StarterAssetsInputs` / `PlayerInput` / `UpperBodyAim` / `FootstepProbe`） |
| ② | **引用没断** | `PlayerArmature` 有**模型**（不是空壳）；`Animator.Controller` 指向 `MyThreeState`；材质**不是粉红**（粉红 = 装成了 Built-in 版） |
| ③ | **能跑** | `Play` → 控制台 **0 红字**，WASD 能跑、`Space` 能跳、右键上半身会抬 |

> ❌ 如果出现**粉红材质** ⇒ 装错了版本（Built-in 版）⇒ 卸载重装 URP 版。
> ❌ 如果出现 **`Missing Script`** ⇒ 脚本文件缺失（检查是否 `git clone` 完整，或误删了 `Assets/Starter Assets/**/*.cs`）。

## 五、常见错误

| 现象 | 原因 | 修法 |
|---|---|---|
| 满屏粉红 | 装了 Built-in 版素材包 | 卸载 → 装 `Starter Assets - ThirdPerson \| URP` |
| 场景里物体都在，但引用全空 | 当初把 `.meta` 也排除了（GUID 变了） | 只能手工重连；**本仓库没有这个问题，别去忽略 `.meta`** |
| `PlayerArmature` 上组件全红 | `.cs` 被排除或没 clone 全 | 确认 `git status` 干净、`Assets/Starter Assets/**/*.cs` 在盘 |
| 导入后多出一层目录（如 `Assets/Starter Assets 1/`） | 包里已经有一份同路径内容 | 删掉多出来的那份，**只留 `Assets/Starter Assets/`** |

## 六、以后再加一个"要排除的素材包"怎么做（三步）

1. **素材实体**：拷进 `Assets/<包名>/`，在 `UnityPractice/.gitignore` 的 ⑦ 区加一条
   `AnimLab/Assets/<包名>/**/*.fbx`（按实际扩展名补 `.png` / `.wav` / `.tif` …）
2. **保留 `.meta`**：**不要**加 `*.meta` 的忽略规则（会断 GUID）
3. **本文补一节**：包名 / Asset Store 链接 / 需要哪个版本（URP？）/ 导入路径 / 判据

> 📚 **素材原件建议另存一份**：把下载的素材包原件放到**仓库外**任意目录（作者放在自己机器的素材库里，位置随你），
> 这样重装系统 / 换设备时能直接拿原件恢复，不必再翻商店；顺手记一份来源清单（包名 / 作者 / 许可 / 下载日期 / URL）——
> **这份清单只写来源信息，不要把素材本体一起提交进仓库**（否则又变成"再分发"）。
