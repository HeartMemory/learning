## 今日沉淀

### 输入系统（轮询制）
- 三兄弟：`GetKey`（状态）/ `GetKeyDown` / `GetKeyUp`（只闪一帧的事件）
- **`GetAxis` vs `GetAxisRaw`**：前者平滑（`Gravity=3`，松手约 0.33 秒归零）→ 有缓动；后者瞬时 `-1/0/+1` → 指哪打哪
- **滑行不是物理惯性**：Kinematic 刚体没有质量/摩擦/惯性，位置由代码指定 —— 滑行只来自输入值的平滑。排查时先分清"输入平滑"和"刚体阻尼"两个完全不同的成因
- **轴名表**（`ProjectSettings/InputManager.asset`）：`"Horizontal"` 是查表的**名字**（拼错抛 `Input Axis xxx is not setup`）；默认绑 `left/right` + 备用键 `a/d`；**改表不用改代码**，还能同时吃键盘/手柄；表会进 git
- 与生命周期对照：生命周期是**引擎点名（推）**，输入是**我每帧去问（拉）**

### 双时钟：Update vs FixedUpdate
| | `Update` | `FixedUpdate` |
|---|---|---|
| 频率 | 每帧一次 | 固定 0.02s = **50Hz** |
| 谁驱动 | 渲染循环 | 物理引擎 |
| 一帧跑几次 | 必然 1 次 | 0 / 1 / 多次 |
| 放什么 | 读输入、纯逻辑、UI | **所有物理操作** |
| 时间量 | `Time.deltaTime` | `Time.fixedDeltaTime` |

- 输入放 `Update`：`GetKeyDown` 只在一帧为真，`FixedUpdate` 一帧可能 0 次或多次 → 会漏 / 重复
- `FixedUpdate` 拼错 = 永不执行且不报错（同款"按名字点名"坑）

### Rigidbody2D 与移动语义
- 三种主体类型：**动态**（球，物理全权接管）/ **运动学**（挡板，代码说了算但仍参与碰撞）/ **静态**（地板墙）
- **`transform.position += v` vs `_rb.MovePosition(next)`**：
  - 前者是"直接撬坐标"→ 绕过引擎 → 两套账打架（抖动/穿墙/碰撞失真）
  - 后者是"申请：这一步请把我搬到那儿"→ 引擎执行 + 同步 Transform + 顺带碰撞检测
- `MovePosition` 要**目标位置**而不是增量 → 得自己算 `_rb.position + 位移`；基准用 `_rb.position`（物理账本里的位置）
- `_rb.position += v` **编译不过**（CS0200：只读属性）；`transform.position += v` 能过是因为它有 setter（属性可整体写回）→ 与 09-17 的 CS1612 是同一章知识的不同分支
- 组件：`GetComponent<Rigidbody2D>()`（`transform` 就是白送的 `GetComponent<Transform>()`）；`[SerializeField] private` = **对检查器开窗、对代码关门**；运行时赋值用的引用字段不要加

### 工程坑（今天踩到的）
| 坑 | 现象 | 根因 / 修法 |
|---|---|---|
| 缺 `BoxCollider2D` | 2D 精灵只有 Sprite Renderer | 手动「添加组件」补上；没碰撞体物理引擎当它不存在 |
| 挡板不动 | 播放后怎么按都没反应 | 只算了 `next`，**漏了 `_rb.MovePosition(next)`** |
| 松手滑行 | 松开按键还滑一小段 | `GetAxis` 平滑回落 → 换 `GetAxisRaw` |
| 旧输入 API 抛异常 | `Input.GetAxis` 报错 | 活动输入处理默认「输入系统包（新）」→ 改「两者」（需重启编辑器） |
| 中文乱码 | VS2022 正常、CodeBuddy 全乱 | VS2022 存成 GB2312/936 → 高级保存选项改 **UTF-8 带签名** |
| 检查器面板作用 | 不知道右侧面板叫什么 | 它就是**检查器**：显示当前选中 GameObject 身上挂的所有组件 |
