## 今日沉淀

### 一、Animator 全链路（四个"Anim"别混）

```
AnimationClip（关键帧数据）
   └─ 被 AnimatorController 的【状态】引用
         └─ 被 Animator 组件的 Controller 槽引用
               └─ 运行时由 Animator 驱动到物体上
```

- **「动画」窗口**做 Clip ｜ **「动画器」窗口**做状态机
- 做 UI 淡入要动画 **`CanvasGroup.alpha`**（整组传播），**不是** `Image.color`（只动一块板子，且颜色被写死）
- ⚠️ **窗口预览 ≠ 运行时**：预览是编辑器**直接改属性**（不需要 Controller）；运行时走的是**状态机那条链路** —— 所以"预览能播"从来没证明过"运行时会播"

### 二、⭐ `Time.timeScale` 的"影响力半径"（第二笔账）

昨天第一笔账：**它不随场景重载复位** → `Restart()` 里要还。
今天第二笔账：**它管得比你想象得宽** —— 不只冻物理，还**冻 `Animator`（默认 `Update Mode = Normal`）**。

| `Update Mode` | 跟谁走 | 受 `timeScale` 影响 |
|---|---|---|
| `Normal`（默认） | `Update` | ✅ 受 |
| `Animate Physics` | `FixedUpdate` | ✅ 受 |
| **`Unscaled Time`** | 真实时间 | ❌ 不受 ← **UI 表现层要选它** |

**拿到的分层**：

```
游戏世界（球 / 挡板 / 物理） ← 受 timeScale → 停住 ✓ "暂停"的本意
表现层（黑幕淡入 / 文字）     ← Unscaled    → 继续走 ✓ 结算画面该播完
```

> 顺带一个对照：**`AudioSource` 完全不受 `timeScale` 影响**（音频走独立时钟）——
> 同样叫"表现层"，`Animator` 要改设置，音频什么都不用做。**所以要逐个确认，不能套用。**

### 三、今天真正的主角：三条"看不见的线"

| # | 线 | 一句话 |
|---|---|---|
| 1 | **`timeScale` 的影响力半径** | 它冻的不只是物理；写 `= 0` 之前先问"我到底想冻什么" |
| 2 | **保存链路的长度** | 脚本 → 场景 → 项目设置 → **资产（`.anim` / `.controller` / Prefab）**，四层都得自己管；**一个坏资产能连坐一整片** |
| 3 | **同相位叠加** | 两声完全同时的音效 = "一声更响"（`sin + sin = 2sin` + 哈斯效应）→ 靠**变体**错开相位 |

**三条线的共同点**：**它们都不在代码里读得出来** —— 只能靠"扒文件 + 真跑 + 算一遍"。

### 四、程序化音效：用代码"算"出一张唱片

```csharp
data[i] = Mathf.Sin(2π · freq · t) * Mathf.Exp(-decay * t) * 0.3f;
//              ↑ 音高（Hz）           ↑ 包络（响度轮廓）
```

- **配参口诀**：`decay × duration ≥ 3`（`e⁻³ ≈ 5%`）→ 结尾已衰减到听不见 → **无爆音**
- **必须缓存**：每次撞砖新建 clip = 每次分配 3528 个 `float`（14KB）→ 打 32 块砖 = **450KB GC 垃圾**
  → **和对象池同一个思想**：`_pool` 缓存**对象**，`Sfx._brickHit` 缓存**资产**
- **必须做变体**：3 个音高微差（±6%）随机挑 → 同时撞两块砖才听得出来
- ⚠️ **别用改 `AudioSource.pitch` 的办法** —— `pitch` 是**整台唱机**的属性，会把正在播的第一声也一起变调

### 五、计基随行两段（已落纸在 Unity 笔记第 10 章）

**① 有限状态机（FSM）**：状态**互斥** + 转移条件 + 当前状态。
比一堆 `bool` 强在——**非法状态根本表达不出来**（不是"靠代码记得拦"）。`_isGameOver` 就是最简 FSM。

**② 数字音频与采样定理**：
- 采样率 = 每秒记多少个点；**44100 = 人耳上限 20kHz × 2 + 余量**
- **奈奎斯特**：要还原频率 `f`，采样率必须 > `2f`；不足会**混叠**（电影里车轮"倒转"就是采样率不够）
- **包络** = 套在波形外面的"响度轮廓"；不乘它 → 结尾突变 → **爆音**
- 🔗 **"任何物理量突然突变，都会产生额外的频率成分"** —— 音频里是爆音，视觉里是"闪一下"。**这和"动画要淡入淡出"是同一件事**
