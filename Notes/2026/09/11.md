## 今日沉淀

**栈队列互换（232 ✓ / 225 ✓ 收官）**
- 225 单队列绕圈：`Push` 三步——① `int times = queue.Count` 冻住老元素个数 ② `Enqueue(x)` 新元素入场 ③ 老元素绕圈 `times` 次（出队即入队）→ 队头 = 栈顶，`Pop`/`Top` 各一行
- 双队列中转 vs 单队列绕圈：前者多一个容器、操作量约 2n；后者零额外空间，n 次操作——**同一问题多解的对照意识**
- 232/225 一正一反：232 魔法在"出"（双栈倒手翻转顺序），225 魔法在"入"（绕圈顶到队头）
- **会变的 Count 处理范式**：先把 `Count` 冻进局部变量再循环（`times`），循环条件永不引用会变的集合

**protected（继承知识收官）**
- 三种访问级别：`private` 只有自己 → **`protected` 自己 + 子孙**（外界不行）→ `public` 全世界
- 语法主战场在属性：`public int HP { get; protected set; }`——读公开、写家族内
- 为什么需要它：**父类数据"子类要能用，外界不能碰"** 的矛盾解法（private set 太严、public set 太松）
- 编译错误也是教材：`villager.HP = 999` 在 Main（外界）报"set 访问器不可访问"——一正一反体验边界
- 常量声明了必须用（`HpCost`），消灭魔法数字 = 规则只写一处
