## 今日沉淀

- **类 = 图纸，对象 = 实例；字段 = 数据格子，方法 = 行为**；`new` = 开地皮 + 构造函数填表 + 交地址
- **引用地基课**：值类型变量装值（复印件赋值），引用类型变量装地址（同一对象多个名字，`b.val = 99` 影响 `a`）；null = 空地址
- **`this` = 当前对象自己**：参数与字段同名撞车时必须写；去掉它 `val = val` 是参数自嗨、字段丢值
- **构造函数**：与类同名、无返回值、`new` 时自动执行；默认参数让无参调用天然可用（`new Student()` = 张三/18）
- **属性 = 一对打包的方法**（get/set），`value` 是 set 自带参数；完整属性（私有字段 + 校验门卫）/ 自动属性 `{ get; set; }` / 计算属性 `=>`（只读、无存储、现算）
- **链表五动作**：读值 `cur.val`、改值、走一步 `cur = cur.next`、接线 `tail.next = node`、跳过 `prev.next = node.next`（203 灵魂：节点删不掉自己，只能被前一个跳过）
- **哑节点**：头节点没有前一个 → 造假头挂前面，删完 `return dummy.next`
- 一个方法 N 个对象各自执行：`student1.Introduce()` 说张三、`student2.Introduce()` 说牢大——字段长在对象身上
