### 一、算法：`101` 对称二叉树（"wrapper + 递归内核"分工首题）
- ⭐ 判据：**"子问题的形状，能不能用主函数的签名直接问出来？"** —— 104/226 的子问题还是"一个节点" → 主函数自己递归；101 的子问题是"**两个节点**是否互为镜像" → **形状变了，必须开 helper**
- 对称 = **交叉成对**比较（`a.left ↔ b.right`、`a.right ↔ b.left`）；三个出口（两个都 null ／ 只有一个 null ／ 值不等）
- ⚠️ **对称 ≠ 每层数值回文**（两组陷阱用例：`[1,2,2,2,null,2]`、`[1,2,2,3,null,3,null]` 肉眼都像回文，结构其实不对称）
- 迭代版 = 队列**成对入队 / 成对出队**（承 102 的队列，但**不数层、只配对**）→ 两版互证 + 「树 == 自己的镜像」**性质裁判**
- 语言层三条：① 两个 `TreeNode` 直接 `==` 是**引用比较**（`null == null` 为 `true` 只是恰好）；② **可空分析不跟踪 `^`、也不跟踪索引器 `list[i]`**（10 条 CS8602/8604 → "显式判断 + 取局部变量"后归零）；③ `Mathf.Approximately` 是**相对容差**、**不能判"接近 0"**；`Vector3 ==` 内部已是近似比较

### 二、物理与表现分离（Unity 主线）
- **`Visual` 子物体**：看得见的进 `Visual`；被代码 / 物理读的（`GroundCheck` / `EdgeCheck`）留物理根
- **转身**：翻 `Visual.localScale.x`（**负缩放 = 镜像**）；⭐ **"谁产生的，就在哪一层消费"**；`localScale` 是属性且返回 struct → **CS1612**（取出 → 改 → 整体写回）
- **`Body` 再分一层**：**同一个属性只能有一个写入者**（脚本管 `Visual` 的离散朝向，Animator 管 `Body` 的连续缩放）

### 三、`Order in Layer` 与"平局"
- 2D 绘制顺序 = 排序图层 → 图层内顺序 → 距相机距离；**三级全相同 = 平局，结果未定义**
- 实测两组：`Player`(0) vs `Tilemap`(0) → 玩家**赢**；`Eye`(0) vs `Visual`(0) → 眼睛**输**
- ⚠️ **"层级里越靠下越后画"只是社区观察，不是规则** → 要用 `Order in Layer` 明说
- 现分配：地形 `0` / 金币 `1` / 敌人 `2-3` / 玩家 `3-4`；排序图层暂不加

### 四、金币 + 触发器 + **单例**
- 金币**自治**（承 Breakout 的 `Brick`）：`OnTriggerEnter2D` + **层门卫**（`playerLayer.m_Bits: 128` = `1 << 7`）
- **触发器不参与物理求解** → "**实心碰撞体要精确，触发器够用就行**"（宽容度大反而更好吃）
- **单例**：`public static ScoreManager Instance { get; private set; }` = **编译期的名字 + 运行期的静态槽位**；与 `InputSystem.actions` **同一个机制**
  - ⭐ 判据：**"我要找的是一个唯一的服务，还是广播一条消息？"** → 唯一的**服务**（计分员）用**单例**；一条**消息**（漏球 / 清空）用**事件**
  - 两笔账：`?.` 容错（可能为 null）+ `OnDestroy` 清入口（静态字段**不随场景卸载自动清**）

### 五、Animator（早上那个 **FSM** 的落地）
- 三状态 `Idle` / `Run` / `Jump` + 两个参数（`Speed` / `IsGrounded`）→ 脚本只**报事实**，播哪个由状态机决定；参数名缓存成 hash（与 `_move` / `Camera.main` 同族）
- ⭐ **动画纪律五条**：① 只动画"**纯视觉、无碰撞体**"的一层；② **一个 clip 动过的属性，每个 clip 都要动且首帧写基准**（否则切状态**残留**）；③ **`有退出时间` 全部关掉**（否则迟滞）；④ 转移条件默认 **AND**（要 OR 就建两条）；⑤ **`Any State` 只给"任何状态都可能触发的打断"**（死亡 / 受击），有限转移画明确箭头
- clips：**别留 0 秒长度**（1 帧恒定值也要给一个正的时间跨度）
