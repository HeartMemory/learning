## 今日沉淀

### 一、显式栈迭代三兄弟（一次销掉四题）

完整版见 `CSharp-基础笔记.md` 第 36 章，这里留索引与结论。

| 题 | 口诀 | 关键 |
|---|---|---|
| 144 | 压进去就访问 | **先压右、后压左**（要访问的**后**压 —— 栈后进先出） |
| 94 | 能往左就往左，不能往左就吐一个，再往右 | 内层**压自己**下潜；`cur = cur.right` **无条件** |
| 145 B | 根右左跑一遍 + 整体逆序 | 抄 144、对调两行压栈、倒进第二个栈 |
| 145 A | 便条法（同一节点进栈 3 次） | 栈装 `(节点, stage)` —— 这就是**手写返回地址** |
| 104 | 路线 A + 答案格子 | `Dictionary<TreeNode,int>` 存"孩子的答案" |

- ⭐ 核心原理：**显式栈 = 把"返回地址"从栈帧里搬到台面上**（栈元素从"节点"升级成"节点 + 进度"）。
- ⭐ 三条判据（94 那一场换来）：① 写 `while` 必须能指出"哪一行让条件变假"；② `Pop` ↔ `Add` 配对是**必要不充分**；③ **`null` 是"信息"还是"错误"**（信息必须放行）。
- ⭐ 反直觉结论：**显式栈不省内存** —— 递归 O(h)、显式栈 O(n)（答案要活到父来取 → 只能进外部容器）。

### 三、接地判定：从"探针"升级为"**真接触 + 法线朝上**"

| | 旧（脚底单点圆 `r = 0.15`） | 新（真接触） |
|---|---|---|
| 问的问题 | "脚底**中心**附近有没有地" | "我的碰撞体**真的**贴着某个朝上的面吗" |
| 覆盖宽度 | 脚宽的 **30%** | **整个碰撞体** |
| 边缘表现 | **站得住却跳不了**（回满门被关 → 次数永远是 0） | 站得住就能跳 ✓ |
| 分不出的东西 | 贴墙时把"墙"也当成地问 | —— |

- ⭐ 判据（今天最值钱的一条）：**"物理支撑区域"和"接地判定区域"是两个独立的开关** —— 改碰撞体动前者，改探针/判定动后者。之前的不一致，就是这两个开关各拧各的。
- ⭐ 必须配**法线过滤**：`IsTouchingLayers` 只答"有没有接触"，**贴墙也算** → 空中贴墙会**白送跳次**；所以用 `GetContacts` + `normal.y > 0.7`。判据：**层管"允许不允许接触"，法线管"从哪个方向接触"**。
- ⚠️ 遗留：`y <= 0f` 那道回满门是**代理量**（用竖直速度符号近似"刚起跳"）→ 若将来在边缘出现"次数不回满"，换成显式的**起跳免疫计时器**（已登记回访清单）。

### 四、敌人巡逻：三种"到头"信号

| 信号 | 传感器 | 提前量 | 覆盖 |
|---|---|---|---|
| 前方无地 | `OverlapCircle`（脚前方） | 提前 | 平台边缘、坑 |
| **前方有墙** | `Raycast`（**身体中心高度**） | 提前 | 墙、台阶 |
| 撞到别的物体 | `OnCollisionEnter2D` | 晚一拍 | 敌人、玩家 |

- ⭐ **为什么必须加射线**：地形是**一个** `CompositeCollider2D`（地面 + 墙 + 平台合并成一块）→ 敌人脚踩地面时**已经在和那一个碰撞体接触** → 走到墙边只是"同一对多了条接触点" → **`Enter` 根本不触发**。
  判据：**"是不是同一对碰撞体"决定 `Enter` 会不会触发。**（旁证：撞敌人 / 撞玩家会回头 ✓，因为那是**新的碰撞体对** —— 两条现象互证了这个病因。）
- ⭐ **墙 = 免费的折返点** → **关卡设计可以后置**（今天只用"地面 + 平台 A"两块场地就把机制验完了）。
- ⚠️ 隐蔽坑：悬空探针**分不出"墙"和"地"**（同在 `Ground` 层）→ 平台 A 左端紧贴墙时，探针一直报"有地"、`Enter` 又不触发 → 会**顶墙不动**（射线版治好）。

### 五、判据清单（今天新增，直接可复用）

1. **`while` 自查**：指不出"哪一行让条件最终变假" = 死循环。
2. **`Pop` ↔ `Add` 配对是必要不充分**；真正的不变量是"每弹出一次 = 处理完一个节点并离开它"。
3. **`null` 是"信息"还是"错误"**：错误才守卫；信息必须放行（`cur = cur.right` 不能加 `if`）。
4. **覆盖式 vs 累积式**：状态更新要"从源头重算"，别"在结果上继续算"（探针基准被自己吃掉 → 每步翻符号 → 抽搐；跳跃高度同理）。
5. **写整条向量 = 抢走另一个分量的控制权**（`new Vector2(x, 0)` 把重力对 y 的累积清零）。
6. **"物理支撑区域" ≠ "判定区域"**（两个独立开关）。
7. **层管"允许不允许接触"，法线管"从哪个方向接触"**。
8. **`Enter` 的粒度是"碰撞体对"**，不是"接触点" → 合并碰撞体上的墙要靠射线。
9. **传感器的口径决定它能看见什么**（圆 / 线 / 回调，各答一种问题）。
10. **"形状看起来不搭"不是理由，现象才是理由**（探针要不要升级，先复现"站得住却跳不了"，别为了匹配形状去改）。
11. **回调只改状态，动作留给主循环**（回调里翻 `_dir`，`FixedUpdate` 里交速度 → 转身在**下一个物理步**生效）。
12. **回调名字 / 签名写错 = 静默失效**（"响亮地失败"的例外）→ 只能靠日志证明它有没有被调用。
