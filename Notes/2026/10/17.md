## 今日沉淀

### 一、算法：`103` 二叉树的锯齿形层序遍历

**题眼一句话**：**「遍历顺序」和「输出方向」是两把独立的刀。**

- 装备复用 102（队列 + `int times = q.Count` 取在 `for` 之前），唯一新增 = **每层方向开关**（`layer % 2`）⇒ 该反的层 `Reverse()` 再塞进结果。
- ⭐ 判据：`Dequeue()` 只能从队头取"下一个"、没有"取第几个"（那是 `List[i]` 的活儿）⇒ **方向开关只能装在「往结果塞」这端，出队那端动不了**。
- ⛔ 陷阱：`result.Add(level)` 存的是**引用** ⇒ 必须**先 `Reverse` 再 `Add`**，顺序反了会把"已塞进结果的那一层"一起反掉（反例区专抓）。
- 15 组用例（12 用例 + 3 反例）本地全绿 + 网页 AC。O(n) / O(w)（承 102："形状决定谁更省"）。

### 二、Unity：障碍生成 + 对象池 + 撞障碍结束（Runner 第 3 步）

**① 对象池换官方 `UnityEngine.Pool.ObjectPool<T>`（查证结论）**

| 回调 | 什么时候被调 |
|---|---|
| `Create`（`Func<Obstacle>`） | **只有池空时**（`Get()` 发现没库存）→ `Instantiate` |
| `OnGet`（`Action<Obstacle>`） | 每次 `Get()` → `SetActive(true)` |
| `OnRelease` | 每次 `Release()` → `SetActive(false)` |
| `OnDestroy` | 归还时池已满（≥ `maxSize`）→ `Destroy` |

- 三个配置：`collectionCheck`（防同一对象还两次，`Release` 时 `Stack.Contains` 遍历 + 命中抛异常）、`defaultCapacity`、`maxSize`。
- ⭐ **最易误解的点：`defaultCapacity` ≠ 预分配** —— 它是内部 `Stack` 的**初始容量**，对象是**懒创建**的（`Get` 时池空才 `new` 一个）。今天摆 8 个障碍 = `Instantiate` 8 次，不是 20 次。🪞 对比 Breakout 的 `Preload()`（主动一次造满 32 块）是**预分配**，两条不同的策略。

**② 程序化摆障碍（职责划分）**

- ⭐ **谁生成、谁摆放**：`ObstacleSpawner.Start()` 循环 `_pool.Get()` + 设 `transform.position`（第 i 个在 `z = spawnStartZ + i * spawnSpacing`）。
- `Obstacle` 只答"被撞怎么办"（`OnCollisionEnter` → 认玩家 → 上报），**不答"我该待在哪"**（位置是算法算出来的，只有生成者知道全局布局）。

**③ 撞障碍结束（哨兵 → 裁判 → 停手）**

- `Obstacle.OnCollisionEnter`（哨兵）→ `GameManager.NotifyPlayerLost()`（裁判，幂等锁）→ 置 `_isGameOver = true`。
- 停手 = 玩家/相机每帧读 `GameManager.Instance.IsGameOver`，命中就 `return`（`Update`/`FixedUpdate`/`LateUpdate` 开头各一行）。

### 三、⭐⭐ 两条架构判据（今天最值钱的收获，见 Unity 笔记第 31 章）

1. **一次性响应用事件，持续条件读状态** —— "停手"是每帧判断 ⇒ 读状态；"弹出面板/播音效"是状态一变做一件事 ⇒ 订阅事件。`OnGameOver` 事件留着（未来结算面板用），停手不靠它。
2. **`timeScale = 0` 只冻结"时间"** —— 冻结不了"读输入 + 直接赋值"（视角那一路零阻尼、不乘 deltaTime）。

### 四、计基随行（3D 数学续）：程序化摆位置 = 参数方程

- **今天那行坐标账就是参数方程**：`P(i) = (0,0,spawnStartZ) + i·spawnSpacing·(0,0,1)` = 起点 + 参数 × 步长 × 方向。
- ⭐ **方向写成单位向量，是为了把「往哪走」和「走多远」分开**：`(0,0,1)` 只管方向（长度恒 1）、`i·spawnSpacing` 只管距离（标量米）。
- **同一套公式换方向向量 = 不同形状**：一排（方向固定）／一圈（`P(θ)=中心+半径·(cosθ,0,sinθ)`）／网格（`P(r,c)=P0+r·rowDir+c·colDir`）—— Breakout 摆砖就是网格的二维版。
- **单位向量是 3D 数学的"通用货币"**：昨天"点乘 = cos 夹角"的前提就是两个向量都归一化。
