## AI 判据数字（今日第一天，从这栏开始累计）

| 指标 | 数值 |
|---|---|
| 模型 | `deepseek-flash`（BASE_URL = `https://api.deepseek.com`） |
| prompt_tokens | **38**（两次一致） |
| completion_tokens | **58 / 72**（两次不同） |
| total_tokens | **96 / 110** |
| **reasoning_tokens** | **38 / 47** ← 占 completion 的 65%；**该模型默认走思考模式** |
| 端到端耗时 | **1254.49 ms / 1303.34 ms** |
| 调用次数 | 2 次（同一 prompt） |
| 预估成本 | 未结算（本日调用量太小；S1 起按「百万 token 单价 × 实测用量」算） |

⭐ **两个数字的含义**（不是"感觉"）：
- **`reasoning_tokens` 占了 completion 的 65%** ⇒ 计费口径要按 `total_tokens` 算，不能按"输出字数"估
- **同 prompt 两次 `total` 差 14 token** ⇒ 输出非确定性 ⇒ **任何"通过率"都必须跑 N 次取分布**
