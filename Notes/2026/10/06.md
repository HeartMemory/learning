## 三句话复盘

1. **今天最大的收获**：**"分层"再一次救了命 —— 但这次救的是"职责"而不是"对象"**。今天的结构是三层，各自只有一个家：**哨兵**（`FailZone` / 敌人：只判"是不是玩家"+ 喊一声）、**裁判**（`GameManager` 单例：唯一出口，上锁 → 改状态 → 广播）、**订阅者**（`DeathPanel` 面板淡入 / `PlayerController` 停手，各自订阅同一个事件）。裁判**完全不认识**这两个订阅者 —— 以后加"死亡音效 / 统计"只是多一个订阅者。
2. **今天最大的教训**：**不要用"连续量"去判"离散状态"**。回满跳次的门用了 `y <= 0f`（竖直速度符号）去近似"我刚落地"这个**离散状态** → 移动落地时接触求解的**残差是 `+0.0000349`**（微正）→ 门被关 → 不回满 → 跳被拒；而 `_jumpRequested` 又是"即时作废" → **按键被吃掉，控制台一声不响**。更深一层的坑：**`F4` 把 `+0.0000349` 打印成 `0.0000`** —— 打印自己也在骗我。

### 一、算法：`110` 平衡二叉树（"返回值携带**复合**信息"首题）
- `104` 是"答案装在返回值里"；本题要多回一样："**这棵子树是否已崩**" → 元组 `(bool ok, int height)`
- ⭐ 判据：**返回值的表达式里必须出现"孩子的返回值"** —— 不出现，那不是"子树的高度"，只是"我自己的坐标"
- 两版实测症状（**根因同一处、症状镜像反转**）：把 `ok`/`high` 放进**参数** → 除空树外全 `false`；只把条件从 `> 1` 改成 `<= 1` 并补 `.ok` → 除空树外全 `true`
- ⚠️ 实测：**每个孩子调 4 次**（`.high` 两次 + `.ok` 两次）→ `2^d` **指数爆炸** → **2000 节点链 25 秒跑不完（卡死）**
- ⭐ **推翻一个标签**：「斜链 = O(n²)」**不成立** —— 链的根上一眼就崩，只付一次全树高度（实测 **4,000 次**）；真判据 = 朴素法代价 ≈ **Σ(子树大小)**，**"在哪里发现答案"决定它亏多少**

### 二、Unity：死亡与重开（第 20 章第一、二节）
- **哨兵 → 裁判 → 订阅者** 三层；致命源统一走 `GameManager.Instance?.NotifyPlayerLost()`
- ⭐ 判据分层：**唯一的"服务"用单例**（听众只有 1 个；敌人是**预制体**，裁判拖不了它的引用）；**一条"消息"用事件**（听众未知/会变）
- **幂等门卫必须放裁判**（玩家可能同时压中两块 `FailZone` 盒子 + 被敌人撞）→ 没门卫 = 面板淡入两次 + `LoadScene` 两次
- ⭐ **`timeScale = 0` 只冻"世界"，不冻"你"**：`Update` / 渲染属性 / UGUI 点击 / 音频都照跑；`FixedUpdate` / 物理 / `Animator`（Normal 模式）自动停
  - 踩坑：**先做完冻结后角色照样转身**（转身在 `Update`、改的是 `localScale`）→ `PlayerController` 订阅 `OnGameOver` → `enabled = false`
  - 判据：**"冻结世界" ≠ "停手"**

### 三、Unity：伤害判定 + 追逐（第 20 章第三、四节）
- 伤害走**碰撞回调**（敌人碰撞体与刚体同在根 → 回调一定到根）；⚠️ **同一回调里"伤害筛层、转身不筛层"是故意的**
- 追逐 = `Physics2D.Raycast` 换**掩码**当视线 + **覆盖式速度**；累加式的症状 = "**离开视野后不减速**"
- ⭐ 数值判据：**冲刺速度必须 < 玩家速度**（否则是"必死"不是"躲避"）
- ✅ 昨天登记的"冲刺撞到玩家不回头"**今天自动消失**：撞到 = 玩家死 → 世界冻结 → 来不及"扑 → 弹回 → 再扑"

### 四、修 bug：零容差判据 vs 离散状态（今天最值钱的一课）
- 排查三步：**先排配置**（扒刚体 `m_Constraints: 4` = 冻结旋转 → 排除"箱体微倾"）→ **一行插桩分开两道门** → ⚠️ **看符号就打布尔，别信 `F4`**
- 实测铁证：`g=True y=3.489852E-05 gateB=False left=0` → 门 B 被残差关掉 → 不回满 → 跳被拒、意图被吃掉 → 连锁**掉下平台 → 死**
- 修法：**回满改判"接地的上升沿"**（`isGrounded && !_wasGrounded`，彻底不看速度），天然满足"起跳后不白送次数"
- ⚠️ 收尾踩坑：新判据**插在旧判据上面**（没替换）→ 两行 `_jumpsLeft = maxJumps` 意图相反 → **死代码 + 自相矛盾 = 下一个 bug 的温床**

### 五、语言层（第 39 章第二、三节）
- **元组元素名是编译期信息**：运行时只有 `Item1`/`Item2`，反射问不出名字；丢了会 **CS1061**，被静默丢弃是 **CS8123**（只是 warning）→ 名字是**文档**不是**护栏**（防不住"两样传反"）
- **位掩码三件套** + **层号 vs 掩码**（`128` vs `7`，混用永远不成立）；`LayerMask` 只有 `value` / `NameToLayer` / `LayerToName` / `GetMask`，**没有 `CompareLayer`**
- **`&` vs `&&`**：一个 = 按位/不短路；两个 = bool/短路 → 空引用守卫必须用 `&&`
